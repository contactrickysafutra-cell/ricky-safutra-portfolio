# Ricky Safutra — Portfolio

Static portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and contact links
- `style.css` — layout, typography, responsive styles, and icon styling
- `script.js` — mobile navigation and footer year
- `assets/ricky-photo.jpg` — optional profile photo; add your own image

## Deploy on GitHub Pages
1. Upload/replace `index.html`, `style.css`, `script.js`, and this README in the repository root.
2. If you want a portrait, upload your image as `assets/ricky-photo.jpg`.
3. In repository Settings → Pages, select the `main` branch and `/ (root)` if not already selected.
4. Wait for GitHub Pages to publish the changes.

The contact icons use inline SVG. WhatsApp opens a prefilled message:
“Halo Ricky, saya [Nama]. Saya tertarik untuk terhubung dengan Anda setelah melihat portofolio Anda. Apakah kita bisa berdiskusi lebih lanjut?”
