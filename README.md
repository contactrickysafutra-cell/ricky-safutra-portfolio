# Website Portofolio Ricky Safutra

Website statis responsif menggunakan HTML, CSS, dan JavaScript. Dirancang untuk dapat dipublikasikan gratis dengan GitHub Pages.

## Isi folder
- `index.html` — struktur dan konten website
- `style.css` — desain dan responsivitas
- `script.js` — menu mobile dan tahun footer
- `assets/` — tempat menyimpan foto profesional

## Sebelum dipublikasikan
1. Siapkan foto profesional milik sendiri dalam format JPG.
2. Simpan fotonya di folder `assets/` dengan nama `ricky-photo.jpg`.
3. Buka `index.html` dan ganti:
   - `emailkamu@example.com` dengan email profesional.
   - tautan LinkedIn contoh dengan tautan profil yang benar.
   - lokasi dan narasi profil agar sesuai fakta.
4. Tinjau semua keahlian dan proyek. Hapus atau ubah hal yang belum sesuai pengalaman.
6. Studi kasus Talent Sourcing Strategy ditandai ongoing; perbarui status hanya jika ada perkembangan yang dapat diverifikasi.
7. Candidate Screening Framework ditandai sebagai contoh konseptual; jangan menyebutnya sebagai proses resmi atau hasil kerja terukur jika belum diterapkan dan diverifikasi.
5. Jangan unggah CV kandidat, data pribadi, atau dokumen internal perusahaan.

## Melihat website di komputer
Buka `index.html` di browser. Untuk hasil terbaik, gunakan VS Code dan ekstensi Live Server, atau unggah ke GitHub Pages.

## Publikasi gratis dengan GitHub Pages
1. Buat akun di https://github.com/ jika belum punya.
2. Buat repository baru bernama `ricky-safutra-portfolio`.
3. Pilih repository Public.
4. Unggah `index.html`, `style.css`, `script.js`, dan folder `assets`.
5. Buka Settings → Pages.
6. Di bagian Build and deployment, pilih Deploy from a branch.
7. Pilih branch `main` dan folder `/ (root)`, lalu Save.
8. Tunggu proses deployment selesai. GitHub akan menampilkan URL website di halaman Pages.

URL umumnya berbentuk `https://USERNAME.github.io/ricky-safutra-portfolio/`.

## Catatan
Foto tidak disertakan karena website perlu menggunakan foto profesional milik pemilik portofolio. Jika belum ada foto, website tetap tampil dengan placeholder RS.
